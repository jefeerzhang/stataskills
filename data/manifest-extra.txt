# stataskills 项目级扩展数据集清单
#
# 与 manifest.txt 的关系：
#   - manifest.txt 是 data/agis6/ 下 AGIS6 教材配套数据集的单一来源；
#   - 本清单是 data/<子目录>/ 下项目扩展数据集的单一来源，包含两类：
#       * 外部来源再分发/衍生数据（如 data/synth/、data/webuse/）；
#       * 项目内脚本生成的可复现教学数据（如 data/selection/）。
#     两类数据都不是 AGIS6；各自 README.md 按对应治理分支留档来源或生成 provenance、
#     许可（仅外部来源适用）与复现信息。
#   - 两份清单由 verify/run-verify.sh 同时校验，互不重叠。
#
# 格式：每行一个 .dta 基名（不含后缀）；空行与 # 开头的行为注释。
# 基名按字母序登记（harness 不强制，但人工维护友好）。
#
# 数据治理分支与维护步骤：
#   - 外部来源/再分发数据：必须提供 data/<子目录>/README.md，记录来源、许可和
#     provenance；必须提供 checked-in download_*.sh，并在脚本中用 EXPECTED_SIZE
#     做字节校验。维护时先审来源/许可，再运行下载脚本并核对 EXPECTED_SIZE，更新
#     README 的 provenance/字节信息，最后在本清单登记基名。
#   - 项目内生成数据：必须提供 README.md，记录固定 Stata version、seed、完整 DGP、
#     checked-in build do-file、schema 和数值不变量；不要求 download_*.sh、
#     EXPECTED_SIZE 或外部许可。维护时修改 build do-file 后用固定版本/seed 重建，
#     运行脚本中的构建断言和验证 harness，核对 README/schema/数值不变量，再在本清单
#     登记基名。
#
