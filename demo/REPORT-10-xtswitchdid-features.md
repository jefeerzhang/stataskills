# 讲稿：`xtswitchdid` 选定之后，把十个开关一个个打开

> 承接 `REPORT-09-xtswitchdid-routing.md`。那一篇回答的是「这份数据该不该用 `xtswitchdid`」。

## 0. 一页速览

这份数据是**故意造出来刁难传统方法的**。它有三个特征：

1. **处理是多值的**（0 / 1 / 2，三个水平），不是「处理 vs 未处理」。
2. **处理会来回切换**，而且**方向不对称**——有的县升档，有的县降档。
3. **2020 年结局故意缺失**，用来演示缺失年份怎么影响暴露期窗口。

在这份数据上，`xtswitchdid` 有十个可调开关。每个开关都对应一个真实存在的设计问题。下面是一句话版本：

| 开关 | 它在解决什么问题 | 不用会怎样（同口径实测） |
|---|---|---|
| `neffects()` | 暴露期窗口开多长 | total 从 `-0.951` 漂到 `-1.135`，**这个数字没有唯一答案** |
| `switchgroup(in)` | 只留升档县 | total `-1.045` → `-1.153` |
| `switchgroup(out)` | 只留降档县 | total `-1.045` → `-0.830`，**下降约 21%** |
| `controlgroup(never)` | 只用从不切换的县做对照 | total `-1.045` → `-1.078`，**几乎不动** |
| `path()` | 只估一条路径 | total `-1.045` → `-1.617`，**样本掉到 1/4** |
| `supergroup()` | 只在全国内比较 | total `-1.045` → `-1.081`，**SE 从 .091 涨到 .126** |
| `raw` | 不看归一化，看原始效应 | **曲线形状完全不同**：归一化一路降，raw 先升后平 |
| `commonswitchers` | 固定同一批 switcher | total `-1.083` → `-1.352`，**差 0.27，比上面所有开关都大** |
| 隔年采样 | 面板间隔不是 1 年 | total `-1.045` → `-0.951` |

**这份数据上没有两个开关是「随便选都一样」的。这就是这一篇要讲的全部内容。**

## 1. 数据生成过程（DGP）

### 1.1 为什么要自己造数据

真实数据不可控。你不知道真值是多少，所以没法判断估计量是对是错；你也不知道某个开关动了之后变化来自设计还是来自噪声。

教学数据必须反过来：**先写死真值，再让估计量去追。** 追不上，我们才能确定是估计量的性质，而不是数据的问题。

所以这份数据的生成过程有两条硬约束：

1. **每一个开关都要有真实来源。** 十个开关背后要有十件真实存在的事——升降档不对称、批次差异、路径异质、省趋势、缺失年份——不能靠噪声凑。
2. **真值必须可查。** 生成完把 `tau` / `d0` / `f` / `rate` / `ramp` 存进数据集，任何估计都能和真值逐期对照。

### 1.2 全流程一览

脚本 `data/did-routing/build_switching_features.do`（167 行，日志同名 `.log`，以 `DONE_BUILD_SWITCHING_FEATURES` 结尾）。分七步：

| 步 | 做什么 | 产出变量 | 服务的开关 |
|---|---|---|---|
| 1 | 面板骨架 | `id` `year` `province` `typ` | F1 F7 |
| 2 | 处理路径 | `dose` | F2 F3 F4 F6 |
| 3 | 路径元信息 | `d0` `f` `ell` `dev` | F6 F8 |
| 4 | 真值效应函数 | `rate` `ramp` `tau` | F8 F9 |
| 5 | 不可观测成分 | `u` `theta` `x1` `e` | F1 F7 |
| 6 | 结局方程 | `y` | 全部（尤其 F10） |
| 7 | 交付前自检 | 真值表、计数核对 | — |

全局设定：

```stata
* 固定 Stata 版本，保证别人重跑得到同样行为
version 19.5
* 固定随机数种子：后面所有 rnormal() 都听它的
set seed 20260929
set obs 4480  // 面板总观测数 = 280 县 × 16 年
```

三行分开看：`version` 管**命令行为**，`set seed` 管**随机数**，`set obs` 管**样本量**。

**同一个 seed 下重跑必然得到同一份数据。** 换一个 seed，`u` / `theta` / `x1` / `e` 全变，但**真值 `tau` 不变**——种子只影响噪声，不影响设计。这个分离很有用：想知道一个结论是「碰巧」还是「稳的」，换个种子重跑就知道。

### 1.3 第 1 步：面板骨架

```stata
* ===== 第 1 步：造出「280 个县 × 16 年」的平衡面板 =====
* 观测总数 = 280 县 × 16 年；必须最先写，_n 才有意义
set obs 4480
* 观测 1-16 → 县 1；17-32 → 县 2 …… 直到县 280
gen long id = ceil(_n/16)
* 按 id 重排后组内 _n = 1..16 → 年份 2010..2025
bysort id: gen int year = 2009 + _n
* 县 1-10 → 省 1；11-20 → 省 2 …… 共 28 个省
gen byte province = ceil(id/10)
* 县 1→1，县 2→2 …… 县 7→7，县 8→0，县 9→1 …… 共 8 类
gen byte typ = mod(id, 8)
```

逐行说明：

| 行 | 命令 | 它在干什么 | 结果 |
|---|---|---|---|
| 1 | `set obs 4480` | 不读任何数据，直接指定行数 | 空数据集，4,480 行 |
| 2 | `gen long id = ceil(_n/16)` | `_n` 是**当前行号**（1…4480）；`ceil` 向上取整 | 每 16 行共用一个 `id`，取值 1…280 |
| 3 | `bysort id: gen int year = 2009 + _n` | 先按 `id` 排序，组内 `_n` 变成 1…16 | 每县 16 年，`year` = 2010…2025 |
| 4 | `gen byte province = ceil(id/10)` | 用 `id`（不是 `_n`）做除法 | 每 10 个县一个省，共 28 省 |
| 5 | `gen byte typ = mod(id, 8)` | `mod` 取余数，余数 0–7 正好 8 类 | 8 类路径，每类 35 个县 |

**第 3 行是全段的机关。** `_n` 在 Stata 里始终是「当前排序下的行号」：第 2 行的 `_n` 是全局行号 1…4480，第 3 行前面加了 `bysort id:` 之后，`_n` 变成县内序号 1…16。同一批数据、同一个 `_n`，两种含义——这是本 DGP 最容易读错的一行。

**为什么 `id` 用 `long`、其他用 `byte`：** `byte` 只能存 −127…100，`province`（≤28）和 `typ`（≤7）够用；`id` 要到 280，用 `byte` 会溢出成负数，所以必须用 `long`。这是类型问题，不是风格问题。

四个变量构成三层结构：

| 变量 | 层级 | 作用 |
|---|---|---|
| `id` | 面板单位 | `group()`、聚类层、`absorb()` 的对象 |
| `year` | 时间 | 2010–2025，16 年，`xtset id year` 后为 `strongly balanced` |
| `province` | 超组 | `supergroup()` 的对象；也是省特有趋势 `theta` 的载体 |
| `typ` | 设计标签 | 决定该县走哪条 `dose` 路径 |

**一处必须点明的结构问题**：`typ = mod(id,8)` 与 `province = ceil(id/10)` **不独立**。每个省的 id 是连续的 10 个（第 k 省 = id `10k+1` … `10k+10`），对应的 typ 序列每次错开 2 位。所以**省内各 typ 的县数是不均的**（第 1 省：typ1 和 typ2 各 2 个，其余各 1 个），而且不均的方式逐省变化。

这不是失误，是**故意留的**：它让「按 typ 分组比较」和「按省分组比较」不再等价，从而制造出 `supergroup(province)` 存在的必要（见 1.7 节）。

### 1.4 第 2 步：构造处理路径 `dose ∈ {0, 1, 2}`

这一整段是本数据的灵魂。设计原则：**三个初始水平（0/1/2）各自都配「从不切换」和「切换」两类县；切换县里升档与降档成对出现；另加一类非吸收往返。**

```stata
* ===== 第 2 步：构造处理路径 dose ∈ {0,1,2} =====
* 思路：先给每个 typ 一个初始值，
* 再用 `year >= f` 把切换之后的年份覆盖掉。
* 因为 replace 是「按行顺序执行」，
* 同一个 typ 下面写几行就能依次叠加。
* 全体先默认为 0（这一行同时定义了 typ0）
gen byte dose = 0

* --- A 组：never switcher，全程不动，
* 三个初始水平各留一个 ---
* typ1：初始 1，永远 1
replace dose = 1 if typ == 1
* typ2：初始 2，永远 2
replace dose = 2 if typ == 2
* typ0 走默认的 0，不需要 replace


* --- B 组：早批（2012 首次切换），暴露期最长，
* 能撑到 ℓ=14 ---
* typ3：0 → 1，升档 +1
replace dose = 1 if typ == 3 & year >= 2012
* typ4 第 1 行：把初始值 1 铺满全时段
replace dose = 1 if typ == 4 & year <= 2011
* typ4 第 2 行：再把 2012 之后覆盖成 2
replace dose = 2 if typ == 4 & year >= 2012
* typ7 第 1 行：铺初始值 2
replace dose = 2 if typ == 7
* typ7 第 2 行：2 → 1，降档 −1
replace dose = 1 if typ == 7 & year >= 2012
* typ7 第 3 行：1 → 0，再降 −1（非吸收）
replace dose = 0 if typ == 7 & year >= 2018

* --- C 组：晚批（2017 首次切换），只能撑到 ℓ=9 ---
* typ5：0 → 2，升档 +2
replace dose = 2 if typ == 5 & year >= 2017
* typ6 第 1 行：铺初始值 2
replace dose = 2 if typ == 6 & year <= 2016
* typ6 第 2 行：2 → 1，降档 −1
replace dose = 1 if typ == 6 & year >= 2017
```

逐行说明（读法：`if` 后面是**选中哪些行**，`=` 后面是**把这些行改成什么**）：

| 行 | 选中的县 | 选中的年份 | 效果 |
|---|---|---|---|
| 1 | 全体 | 全体 | `dose = 0`，即所有 typ 的默认起点 |
| 3 | typ1 | 全体 | 恒为 1（never） |
| 4 | typ2 | 全体 | 恒为 2（never） |
| 7 | typ3 | 2012 及以后 | 0 → 1，**一次切换，吸收** |
| 8 | typ4 | 2011 及以前 | 铺初始值 1 |
| 9 | typ4 | 2012 及以后 | 覆盖成 2，**升档 +1** |
| 10 | typ7 | 全体 | 铺初始值 2 |
| 11 | typ7 | 2012–2025 | 2 → 1 |
| 12 | typ7 | 2018–2025 | 1 → 0，**两次切换，非吸收** |
| 14 | typ5 | 2017 及以后 | 0 → 2，**升档 +2** |
| 15 | typ6 | 2016 及以前 | 铺初始值 2 |
| 16 | typ6 | 2017 及以后 | 2 → 1，**降档 −1** |

**三个必须看懂的「技术动作」：**

1. **第 8–9 行、第 15–16 行是成对的。** 只写第 9 行（`year >= 2012` 改成 2）会让 typ4 在 2011 年还是默认值 0——初始水平就错了。所以必须先铺满初始值，再覆盖。这个「先铺后盖」的模式在 typ4 / typ6 / typ7 上都出现。
2. **顺序不能换。** Stata 的 `replace` 从上往下执行。第 12 行之所以能把 typ7 改成 0，是因为第 11 行已经把它从 2 改成了 1。把第 11、12 行对调，结果会完全不同。
3. **`&` 是「并且」，不是「或者」。** `typ == 7 & year >= 2012` 选中「既是 typ7、又落在 2012 年之后」的那些行。写 `|`（或者）就全错了。

**注意 `typ4 / typ6 / typ7` 的写法**：都是「先铺满初始值，再用 `year >= f` 覆盖」。Stata 的 `replace` **按行顺序执行**，所以 typ7 的三行依次把它从 2 改成 1、再改成 0：

| typ7 的年份 | 执行第 1 行后 | 第 2 行后 | 第 3 行后 |
|---|---|---|---|
| 2011 | 2 | 2 | 2 |
| 2012–2017 | 2 | **1** | 1 |
| 2018–2025 | 2 | 1 | **0** |

路径结果：

| typ | 路径 | 首次切换年 | 方向 | 县数 | 效应符号 |
|---|---|---|---|---|---|
| 0 | 恒为 0 | — | never | 35 | 0 |
| 1 | 恒为 1 | — | never | 35 | 0 |
| 2 | 恒为 2 | — | never | 35 | 0 |
| 3 | `0 → 1` @2012 | 2012 | 升档 +1 | 35 | 负 |
| 4 | `1 → 2` @2012 | 2012 | 升档 +1 | 35 | 负 |
| 5 | `0 → 2` @2017 | 2017 | 升档 +2 | 35 | 负（最负） |
| 6 | `2 → 1` @2017 | 2017 | 降档 −1 | 35 | **正** |
| 7 | `2 → 1` @2012 → `0` @2018 | 2012 | 降档 −1, −1 | 35 | **正** |

这张表是整个讲稿的地基。四处的设计意图：

- **三个初始水平都齐全**：0 有 typ0/3/5，1 有 typ1/4，2 有 typ2/6/7。`xtswitchdid` 只在共享同一初始处理水平的组之间做差；**某个初始水平若没有 switcher，Stata 会把整个水平丢掉并在表头打一条 note**。第一版数据在这里踩过坑——typ4 当时写成 `2→1`，初始水平 1 一个升档县都没有，整组被丢，表头只剩两行。
- **升降档成对且不对称**：升档县（typ3/4/5）效应为负，降档县（typ6/7）效应为**正**。这才让 `switchgroup(in)` 与 `switchgroup(out)` 有真实差别（否则两边就是同一批人）。
- **早批 / 晚批分批**：早批 2012 切，晚批 2017 切。晚批暴露期更短，所以**不同暴露期用到的 switcher 构成不同**——这是 `commonswitchers` 存在的理由。
- **吸收与非吸收并存**：typ3/4/5 切过去不回头；typ7 切两次（2012、2018）。这是 `path()` 存在的理由。

### 1.5 第 3 步：路径元信息

要让效应函数知道「这个县偏离初始水平多少」和「已经偏离了几期」，先把四个元信息算出来：

```stata
* ===== 第 3 步：路径元信息 =====
* 这四个变量不直接进结局方程，但真值 tau 要用它们算。

* 只在 2010 那一行赋值，其余年份留缺失
gen byte d0 = dose if year == 2010
* 先全体设 0，代表「从不切换」
gen int f = 0
* 早批三个 typ 的首次切换年
replace f = 2012 if inlist(typ, 3, 4, 7)
* 晚批两个 typ 的首次切换年
replace f = 2017 if inlist(typ, 5, 6)

* 暴露期，先全体设 0
gen int ell = 0
* 只在切换当年及之后计数；切换当年 = 第 1 期
replace ell = year - f + 1 if f > 0 & year >= f

* 当期剂量 − 初始剂量
gen double dev = dose - d0
```

四个变量的定义（**这是报告里所有「第 ℓ 期」说法的来源**）：

| 变量 | 定义 | 取值示例 |
|---|---|---|
| `d0` | 该县 2010 年的 `dose` | typ7 的 `d0 = 2` |
| `f` | 首次切换年；never 组为 0 | typ3/4/7 → 2012；typ5/6 → 2017 |
| `ell` | `year - f + 1`；切换前与 never 组为 0 | typ3 在 2012 年 `ell = 1`，2013 年 `ell = 2` |
| `dev` | `dose - d0` | typ3 在 2012 年后恒为 +1；typ7 在 2012–17 为 −1，2018 后为 −2 |

**`dev` 是这套设计的核心概念**：它同时编码了「切了多大」和「往哪个方向切」。升档 `dev > 0`，降档 `dev < 0`，never 组 `dev = 0`。

（`ell` 和 `dev` 是中间变量，**不存进最终 `.dta`**——第 7 步的 `keep` 里没有它们。演示脚本会自己重算 `ell`，因为估计时要按 `ell` 分组看暴露期。）

### 1.6 第 4 步：真值效应函数

真值**不能写成常数**。如果真实效应处处相同，这份数据就测不出十个开关的差别了。所以写成：

```stata
* ===== 第 4 步：真值效应 tau =====
* 效应不是常数：它随「切换幅度」和「暴露期」变化。
* 分三块写：rate、ramp、tau。

* 先全体设 0，never 组（typ0/1/2）就停在这里
gen double rate = 0
* 早批升档：永久水平 0.70
replace rate = 0.70 if inlist(typ, 3, 4)
* 晚批升档：0.55（比早批小）
replace rate = 0.55 if typ == 5
* 早批降档：0.45
replace rate = 0.45 if typ == 7
* 晚批降档：0.30（最小）
replace rate = 0.30 if typ == 6

* 每期累加速度，先全体设 0
gen double ramp = 0
* 早批：每多暴露 1 期，多累 0.20
replace ramp = 0.20 if f == 2012
* 晚批：0.12 ← F9 能否验出来的伏笔
replace ramp = 0.12 if f == 2017

gen double tau = -dev * (rate + ramp * min(ell, 4))
* 从左往右读：
*   1. dev           幅度与方向（+1/+2/−1/−2）
*   2. 最前面的负号   升档使结局变差、降档使结局变好
*   3. rate          切换的永久水平
*   4. ramp          累加项，随暴露期线性增长
*   5. min(ell, 4)   第 4 期封顶，ℓ=5,6,7… 都按 4 算
*   6. 括号整体      每单位偏离造成的效应大小
```

**逐字读法：**

| 元素 | 它在做什么 | 举个数 |
|---|---|---|
| `gen double rate = 0` + `replace` | 先给全体一个默认值，再按 typ 逐个覆盖 | never 组始终 `rate = 0` |
| `inlist(typ, 3, 4)` | 等价于 `typ == 3 | typ == 4`，但更短 | typ3 / typ4 共用 0.70 |
| `f == 2012` | 用**首次切换年**而不是 typ 来分组 | 早批 = typ3/4/7 都是 0.20 |
| `min(ell, 4)` | 取小值：ℓ=1,2,3,4 取自身；ℓ=5,6,… 取 4 | ℓ=6 时加的是 `0.20×4 = 0.80` |
| `-dev * (...)` | 先算「每单位偏离的效应」，再乘以偏离幅度 | typ5 的 `dev = 2`，效应翻倍 |

**三个容易写错的地方：**

1. **`ramp` 的分组用 `f`，不用 `typ`。** 因为早批包含升档和降档两类，用 `f` 写一行就够；用 `typ` 得写三行。两者等价，但 `f` 版本不会漏。
2. **`min(ell, 4)` 里的 4 是硬编码的封顶期**。它直接决定了 F1 的 `neffects` 阶梯在第 4 期之后为什么变缓——窗口从 4 拉到 6，真值没变，但分母变大了（见 §3.1）。
3. **`ell` 和 `dev` 必须已经生成。** 这一段依赖第 3 步。如果前面写错，这里的 `tau` 会静默地变成负数或缺失，而不是报错——所以第 7 步的 `table (ell) (typ), statistic(mean tau)` 就是用来抓这类错误的。

$$\tau_{i,t} = -\underbrace{(D_{i,t} - D_{i,0})}_{dev} \times \Big(\underbrace{rate_i}_{\text{永久水平}} + \underbrace{ramp_i}_{\text{累积速度}} \times \min(\ell_{i,t}, 4)\Big)$$

五个部件各自的职责：

| 部件 | 含义 | 服务的开关 |
|---|---|---|
| 负号 + `dev` | 升档有害、降档有益；切换幅度越大，效应越大 | F3 / F4（升降档不对称） |
| `rate` | 切换的**永久水平**；升档 > 降档 | F3 / F4 / F9 |
| `ramp` | **每期累积速度**；早批 0.20 > 晚批 0.12 | F9（`commonswitchers`） |
| `min(ell, 4)` | 第 4 期封顶，曲线先升后平 | F8（raw 的动态） |
| 整个乘法结构 | 效应随 `dev` 与 `ℓ` 变化，**不是常数** | F1（`neffects` 阶梯） |

**手算三例**（对照下面的真值表）：

- typ3 `0→1` @2012：`dev = +1`，`rate = 0.70`，`ramp = 0.20`。ℓ=1 → `−1×(0.70+0.20×1) = −0.90`；ℓ=4 → `−1×(0.70+0.20×4) = −1.50`；ℓ=6 → 仍 `−1.50`（已封顶）。
- typ5 `0→2` @2017：`dev = +2`，`rate = 0.55`，`ramp = 0.12`。ℓ=1 → `−2×(0.55+0.12) = −1.34`；ℓ=4 → `−2×(0.55+0.48) = −2.06`。
- typ7 `2→1` @2012：`dev = −1`，`rate = 0.45`，`ramp = 0.20`。ℓ=1 → `+0.65`；ℓ=4 → `+(0.45+0.80) = +1.25`。**2018 年第二次切换后 `dev = −2`**，ℓ≥7 → `+2×(0.45+0.80) = +2.50`。

实测真值表（`table (ell) (typ) if ell>0, statistic(mean tau)`，日志「0e」段，与手算逐项吻合）：

| typ | 路径 | ℓ=1 | ℓ=2 | ℓ=3 | ℓ=4 | ℓ≥4 |
|---|---|---|---|---|---|---|
| 3 | `0→1` @2012 | −0.90 | −1.10 | −1.30 | −1.50 | −1.50 |
| 4 | `1→2` @2012 | −0.90 | −1.10 | −1.30 | −1.50 | −1.50 |
| 5 | `0→2` @2017 | −1.34 | −1.58 | −1.82 | −2.06 | −2.06 |
| 6 | `2→1` @2017 | **+0.42** | +0.54 | +0.66 | +0.78 | +0.78 |
| 7 | `2→1→0` @2012 | **+0.65** | +0.85 | +1.05 | +1.25 | ℓ≥7 变 **+2.50** |
| 0,1,2 | never | 0 | 0 | 0 | 0 | 0 |

把这几行连起来看，你就拿到了这份数据的「标准答案」：

- **升档有害**：处理水平越高，结局越低，而且**负效应越暴露越大**（−0.90 → −1.50）。
- **降档有益**：typ6/typ7 的效应是**正的**——因为 `dev < 0`，`−dev > 0`。这在经济学上讲得通：把约束降下来，结局变好。**注意这会让传统方法彻底懵掉，后面 TD2 / TD3 会看到。**
- **大幅切换影响更大**：typ5 的 `dev = 2`，效应是 typ3 的两倍。
- **晚批累积更慢**：`ramp` 从 0.20 降到 0.12。这条设计专门让 2012 批和 2017 批**不可比**——传统方法把两批压成一个数时会出错。
- **typ7 有个拐点**（ℓ≥7 跳到 +2.50）：它 2018 年发生第二次切换，`dev` 从 −1 变成 −2。这是 `path()` 存在的理由。

### 1.7 第 5–6 步：不可观测成分与结局方程

```stata
* ===== 第 5 步：不可观测成分 =====
* 三种东西：县固定冲击 u、省趋势 theta、县-年协变量 x1，
* 外加纯噪声 e。

* 只给 2010 那一行抽一个数
gen double u = rnormal(0, 0.5) if year == 2010
* 播到该县全部 16 年 —— 这就是「县固定效应」
bysort id: replace u = u[1]

* 下面要用 by province:，必须先排序
sort province id year
* 标记每个省的第一行
by province: gen byte _firstp = (_n == 1)
* 只给每省第一行抽一个数 → 共 28 个数
gen double theta = rnormal(0, 0.04) if _firstp == 1
* 播到全省 10 个县
by province: replace theta = theta[1]
drop _firstp
sort id year

* 县-年 时变协变量（每个观测独立抽）
gen double x1 = rnormal()
* 独立同分布噪声（每个观测独立抽）
gen double e  = rnormal(0, 1)

* ===== 第 6 步：结局方程 =====
gen double y = 10 + 0.15*province + u ///
             + (0.12 + theta)*(year - 2010) ///
             + 0.2*x1 + tau + e
* 逐项拆开（按在等号右边出现的顺序）：
*   1. 10                      常量截距
*   2. 0.15*province           省水平差异（可观测）
*   3. u                        县固定冲击（县内恒定）
*   4. (0.12 + theta)*(year-2010)   全国趋势 + 省偏离
*   5. 0.2*x1                   可观测协变量的贡献
*   6. tau                      真值效应（要估的对象）
*   7. e                        纯噪声，处理不掉
* 末尾的 /// 是「本行未完，下一行继续」的续行符

replace y  = . if year == 2020  // 抹掉 2020 年的结局
* 协变量也一起抹掉；dose 和 tau 保留
replace x1 = . if year == 2020
```

**各段「播值」手法对照（这一段是整个 DGP 里最集中的编程技巧）：**

| 变量 | 想要的性质 | 做法 | 关键行 |
|---|---|---|---|
| `u` | 县内恒定 | 先按年取一次，再组内播 | `bysort id: replace u = u[1]` |
| `theta` | 省内恒定 | 先按省抽 28 个数，再省内播 | `gen double theta = rnormal(0, 0.04) if _firstp == 1` → `by province: replace theta = theta[1]` |
| `x1` | 每个观测都不同 | 直接 `gen`，不播 | `gen double x1 = rnormal()` |
| `e` | 每个观测都不同 | 直接 `gen`，不播 | `gen double e = rnormal(0, 1)` |

**`[1]` 下标读法：** 在 `bysort` / `by` 前缀下，`u[1]` 指的是**本组第 1 行**的 `u`。所以 `replace u = u[1]` 的含义是「把本组第一行的值，写回本组每一行」——这就是「组内播值」的标准写法。

**`_firstp` 为什么需要：** `rnormal(0, 0.04)` 每调用一次就抽一个数。如果直接 `gen double theta = rnormal(0, 0.04)`，会得到 **4,480 个不同的数**（每个县-年一个），那就不是省趋势了。所以先用 `_firstp` 把抽样限制在「每省第一行」，得到 **28 个数**，再播到全省。

**2020 年为什么只抹 `y` 和 `x1`：** `dose` 和 `tau` 保持完整，这样「真实处理路径」和「真实效应」都不缺，缺的只是观测到的结局。估计量必须自己处理这个缺口——这正是 F8e / F9 里 `effect of exposure 4 cannot be estimated because of missing data` 的来源，也是 F10 非平衡面板的来源。

结局方程逐项：

| 项 | 值 | 性质 | 谁负责处理 |
|---|---|---|---|
| 常数 | `10` | 截距 | 无关 |
| `0.15*province` | 省倍率 | **可观测**的水平差异 | `supergroup()`、固定效应 |
| `u` | `~N(0, 0.5²)`，县内恒定 | **不可观测**的县水平差异 | 差分 / 固定效应 |
| `(0.12 + theta)*(year-2010)` | 0.12 为全国共同趋势；`theta ~ N(0, 0.04²)` 为省偏离 | 全国趋势可差分掉；**`theta` 不可观测且省内相关** | `supergroup(province)` |
| `0.2*x1` | 县-年时变 | 可观测协变量 | `(y x1)` 里的 `x1` |
| `tau` | 真值 | — | 这正是要估的对象 |
| `e` | `~N(0, 1²)` | 幂等噪声 | 处理不掉（这是 SE 的来源） |

三类不可观测量的分工：

| 对象 | 作用 | 谁来处理它 |
|---|---|---|
| `u`（县固定冲击） | 让县之间有水平差异 | 差分 / 固定效应消掉它 |
| `theta`（省趋势，**省内相关**） | 制造**违反平行趋势**的风险，且相关结构在省这一层 | `supergroup(province)` |
| `x1`（时变协变量） | 提供一个可调整的协变量 | `(y x1)` 里的 `x1` |

**`theta` 是本数据最阴的一处，值得单独说清。**

它只按省抽一次（28 个数），然后在省内的 10 个县之间共享。后果有三层：

1. **同一省的县趋势高度相关**，跨省比较才安全。
2. 因为 `typ` 与 `province` 不独立（1.3 节），按 typ 分组比较时，两组的**省内构成**不同，组均 `theta` 也就不相等。
3. 这个组均差的量级在 **0.01–0.02**（`theta` 的 SD 只有 0.04），但**它会随暴露期线性累积**——到第 6 期就是一个 0.06–0.12 量级的伪漂移。

`supergroup(province)` 就是把这个累积漂移限制在省内，从而消掉它。实测它是有效的：加上之后 `estat total` 只从 −1.045 挪到 −1.081，但 **SE 从 0.0912 升到 0.1257（+38%）**——点估计没变，不确定性变诚实了。

**2020 年的处理**：`replace y = . if year == 2020` 和 `replace x1 = . if year == 2020` 把这一年整个抹掉。注意 **`dose` 和 `tau` 在 2020 年仍然完整**，缺的只是结局和协变量。这个设计同时服务两件事：演示「缺失年份吃掉暴露期」（F8e、F9），以及制造非平衡面板（F10）。

### 1.9 这份模拟能验证那十个场景吗

这是本讲稿必须正面回答的问题。逐条对账：

| 场景 | 数据里对应的设计 | 能不能验证 | 实测证据 |
|---|---|---|---|
| F1 基线 | 8 类路径 × 3 个初始水平 | ✅ | 表头三行齐全，三个初始水平都有 switcher |
| F2 初始非零 | typ1/2/4/6/7 初始水平为 1 或 2 | ✅ | 子样本表头只剩 1 和 2 两行 |
| F3 只留升档 | typ3/4/5 升档，typ6/7 降档 | ✅ | 与 F4 对照：`-1.153` vs `-0.830` |
| F4 只留降档 | 同上，方向相反 | ✅ | 表头只剩初始水平 2 |
| F5 never 对照 | 每水平都有 35 个 never 县 | ✅ | 对照池真实存在，不是空的 |
| F6 路径特定 | 8 类 → 5 条不同路径 | ✅ | `pathlen(6)` 分出 5 条，各 35 县 |
| F7 省内比较 | 28 个省 × 10 县，省特有趋势 | ✅ | `theta` 真实存在 |
| F8 raw vs 归一化 | 真值 `tau` 先升后平 | ✅ | 比值精确等于 `dev × ℓ` |
| F9 commonswitchers | 早批/晚批的 `ramp` 不同（0.20 vs 0.12） | ✅ | 与默认差 0.268 |
| F10 隔年采样 | 2020 缺失 + 16 年面板 | ✅ | 暴露期有效数减半 |

**四个关键「能不能验证」的硬证据：**

1. **三个初始水平都有 switcher**（若缺一个，Stata 会整组丢弃并在表头打 note）。修完后的表头：

```
Initial      |
treatment    |      Groups          Obs   Switch out    Switch in    Absorbing
           0 |         105        1,575                       1 2          Yes
           1 |          70        1,050                         2          Yes
           2 |         105        1,575          0 1                        No
```

2. **归一化的分母被精确验证**（F8c/F8e，详见第 3.7 节）。两个单一路径子样本上，`raw / normalized` 的比值恰好等于 `dev × ℓ`，误差在 4 位有效数字内为零。这是全篇最强的一处证据。

3. **`neffects` 阶梯是单调的**（`-0.951 → -1.045 → -1.068 → -1.083 → -1.135`）。如果在数据里真实效应是常数，这个阶梯会走平；它单调放大，说明「越长的窗口纳入越多累积效应」这件事在数据里真实存在。

4. **平行趋势在默认设定下通过**（`chi2(5) = 4.44`，`p = 0.4879`）。基准可信，后面所有开关的比较才有意义。

**结论：这版模拟对十个场景是高度契合的，不是「大概能跑」。每一处差异都能回溯到一个写死的真值参数。**

## 2. 传统方法在这份数据上会怎样

学生最容易跳过这一步。但如果不先看传统方法怎么崩，后面十个开关看起来就是一堆没有动机的参数。

`xtswitchdid` 的定位，官方功能页写得很直白：

> If you have a multivalued treatment or groups that switch in and out of treatment, traditional difference-in-differences (DID) estimators are of little use.

这句话是整篇讲稿的题眼。下面三种做法，对应学生最可能上手的三种「传统方法」。

### TD1：把多值处理二值化，直接塞给 `xthdidregress`

```stata
* 把「多值处理」压成「二元处理」—— 学生的第一直觉
* dose = 1 或 2 都算「已处理」，0 算「未处理」
gen byte treat_bin = (dose > 0)
* (结局 协变量) (处理变量), group(面板单位)
xthdidregress aipw (y x1) (treat_bin), group(id)
```

逐段读法：

| 片段 | 它在说什么 |
|---|---|
| `(dose > 0)` | 逻辑表达式：成立返回 1，不成立返回 0。这是 Stata 里最常用的造虚拟变量写法 |
| `aipw` | 估计算法（增广逆概率加权）；`xthdidregress` 还支持 `ra`（回归调整） |
| `(y x1)` | 第一个括号 = **结局 + 协变量**；`x1` 写在这里意味着要控它 |
| `(treat_bin)` | 第二个括号 = **处理变量**；它必须是括号里的唯一一个变量 |
| `group(id)` | 面板单位。它同时决定默认的聚类层级 |

**这行命令的假设藏在括号外：** `xthdidregress` 默认处理是「二元 + 吸收 + 错时」的。它不会去检查你的数据——它只是算，算出不来才报错（下一个代码块就是报错原文）。

**结果：根本跑不出来。`r(498)`。**

```
units in time period 2010 cannot be treated
The first time period in the estimation sample is 2010. This implies units are
either always treated or are switching between treatment and control, which
violates the model's assumptions.
```

原因很清楚：2010 年就有县 `dose > 0`（typ1/2/6/7），而 `xthdidregress` 假设处理是「吸收 + 错时」的——首期必须没人被处理，之后一旦处理就不回头。

**教学要点：这不是「估计得不好」，而是「连估计都定不下来」。传统工具在这份数据上的失败是结构性的，不是精度问题。**

### TD2：换一个「能跑」的二元编码

学生被 TD1 拦住之后，第一反应一定是「那我换个编码让它能跑」。我们来认真试一次：

```stata
* 换一个「能跑」的二元编码：把「发生过切换」当作「已处理」
* （一次切完不回头）
* 先全体设「未处理」
gen byte treat_ever = 0
* 早批：2012 起永久置 1
replace treat_ever = 1 if inlist(typ,3,4,7) & year>=2012
* 晚批：2017 起永久置 1
replace treat_ever = 1 if inlist(typ,5,6) & year>=2017
* 这次能跑出数
xthdidregress aipw (y x1) (treat_ever), group(id)
```

逐行读法：

| 行 | 它在做什么 | 造成的后果 |
|---|---|---|
| 1 | 全体置 0，保证不存在缺失值 | 无 |
| 2 | typ3/4（升档）+ typ7（降档）在 2012 之后都置 1 | **typ7 被说谎地标成「已处理」** |
| 3 | typ5（升档）+ typ6（降档）在 2017 之后都置 1 | **typ6 被说谎地标成「已处理」** |
| 4 | 扔给 `xthdidregress` | 能跑，但结果已被前两行污染 |

**关键区别在 `year >= f`：** 一旦年份过了 `f` 就永远是 1，**不再回落**——这正是「吸收」假设。而真实数据里 typ6/typ7 的 `dose` 是**往下走**的（2→1、2→1→0）。所以第 2、3 行把一个「剂量下降」的故事硬写成了「处理生效」。这就是下面「错误一」里 805 条说谎观测的来源。

**这次跑出来了**（`TD2_rc = 0`）：

```
Number of cohorts |           3
Never treated     |        1575
            2012 |        1575
            2017 |        1050
Number of obs = 4,200    Number of panels = 280
Estimator:       Augmented IPW
```

数字也出来了。**但它错了，而且错得很隐蔽。**

**错误一：这个编码在说谎。** `treat_ever` 把 typ6 和 typ7 也标成「已处理」——可这两个 typ 实际是**降档**县，`dose` 一直在往下降。数一下：

- `treat_ever == 1 & dose < d0` 的观测：**805 条**
- 其中来自降档县 typ6/typ7 的：**805 条（全部）**

也就是说，这个二元编码把 **805 条「处理强度下降」的观测硬标成「处理生效」**。

**错误二：两个队列的大小关系反了。** 事件研究结果：

| 队列 | 2017 | 2018 | 2019 | 2021 | 2022 |
|---|---|---|---|---|---|
| 2012 队列 | −0.533 | **−0.008** | −0.239 | −0.113 | **+0.040** |
| 2017 队列 | **−0.819** | −0.785 | −0.711 | −0.897 | **−0.536** |

真值里，**早批的效应比晚批大**（`rate` 0.70 + `ramp` 0.20，对比 0.55 + 0.12）。可二元编码给出的排序是：**2012 队列 ≈ −0.3 到 −0.6（甚至 2022 年变成正的），2017 队列 ≈ −0.8。**

**大小关系完全颠倒。**

为什么会颠倒？因为 2012 队列里混着 typ7——它的真值效应是**正的**（+0.65 到 +2.50）。二元编码把它的正效应和 typ3/typ4 的负效应塞进同一个「已处理」筐里，两边互相抵消，队列平均就变小了。这是**加总**造成的失真，不是估计误差。

**错误三：事前系数乱飞。**

| 队列 | 2011 | 2012 | 2013 | 2015 | 2016 |
|---|---|---|---|---|---|
| 2012 队列 | **−0.450** (p=0.012) | −0.241 | −0.343 | −0.534 | −0.528 |
| 2017 队列 | **−0.762** (p=0.000) | **+0.256** | −0.228 | **+0.319** | **+0.153** |

处理前的年份（2011–2016）本该是 0。2017 队列在 2011 年就有 −0.76 的「效应」，2015 年又跳到 +0.32。**平行趋势明显不成立**——这是编码错误在事前暴露出来的信号。

**教学要点：二值化不是「损失一点信息」，它会（a）把方向相反的县混在一起，（b）颠倒真实的大小关系，（c）破坏平行趋势。而这三种错误在校准表里都看不出来——你只有一个数字，它看起来很正常。**

### TD3：最朴素的双向固定效应

```stata
areg y dose x1 i.year, absorb(id) cluster(id)
* 从左往右读：
*   1. y             结局
*   2. dose          处理变量
*   3. x1            协变量
*   4. i.year        年份虚拟量，控「全国共同趋势」
*   5. absorb(id)    吸收县固定效应（280 个虚拟量）
*   6. cluster(id)   聚类到县；不写就是普通稳健 SE
* 第 2 项是全篇的争议点：dose 被压成单一系数，不分暴露期
```

逐段读法：

| 片段 | 它在说什么 |
|---|---|
| `areg` | 吸收式回归：把高维固定效应「抽掉」而不生成虚拟变量 |
| `absorb(id)` | 县固定效应。它把 `u`（县固定冲击）消掉 |
| `i.year` | 年份虚拟变量。它把全国共同趋势 `0.12*(year-2010)` 消掉 |
| `dose` | 唯一进方程的连续处理变量。**它只占一个自由度** —— 这就是失真所在 |
| `cluster(id)` | 聚类到县。因为处理在县级，同县各年不独立 |

**注意 `i.year` 与 `theta` 的区别：** `i.year` 只能吸收**所有县共同**的时间冲击（「0.12 那条线」），它拿**省特有**的 `theta*(year-2010)` 没办法。这就是 F7 里 `supergroup(province)` 要解决的问题——TWFE 在这里也是缺的。

结果：`dose = -1.098048`（SE `.0350884`），`x1 = .1909445`，`R² = .7734`。

一个干净的、极其显著的系数。**但它同样是个伪答案。**

真值里，效应从 **−2.06（typ5 第 4 期）到 +0.78（typ6 第 4 期）**，跨度接近 3 个单位。TWFE 用一个系数把它压平。而且，

**注意一个陷阱**：TD3 的 `-1.098` 和 F1 的 `-1.045` **数值上很接近**。学生一定会问：「那 TWFE 不是挺准的吗？」

答案是不准，但接近得很巧合：

- `xtswitchdid` 的 `-1.045` 是**逐暴露期效应按公式汇总**得到的（下一节的 `estat total` 公式），它可分解、可追溯。
- TWFE 的 `-1.098` 是**所有 2×2 比较的方差加权平均**。Goodman-Bacon (2021) 证明了这个加权里可能含**负权重**，而且当处理效应随时间变化时，已经处理过的单位会被当作对照，从而污染估计——严重的可以让系数的**符号都反过来**。

数值接近不等于含义相同。**这是本篇最值得让学生记住的一句话。**

### 三种传统做法的汇总

| 做法 | 结果 | 失败机制 |
|---|---|---|
| TD1 二值化 → `xthdidregress` | `r(498)`，跑不出来 | 首期已有人被处理，违反「吸收 + 错时」假设 |
| TD2 粘性二元编码 | 跑出数，但**大小关系颠倒**、事前趋势乱飞 | 把降档县标成已处理（805 条），加总抵消 |
| TD3 TWFE 连续处理 | `-1.098`，单系数、极显著 | 真值跨度近 3 个单位被压平；权重可为负且不可分解 |

## 3. 逐个开关：十个场景

下面每一节都按同一个五段结构写，方便对照：

1. **什么时候需要它**——打开数据你会看到什么
2. **为什么默认不够用**——机制，一句话
3. **不用会怎样**——**同口径**对照（两侧 `neffects` 相同）
4. **代价**——样本、SE、命令 note
5. **怎么汇报**——进主文还是附录

> **口径纪律**：本节所有「用/不用某开关」的对照，**两侧 `neffects()` 必须相同**。否则你同时改了两件事，差额无法归因。旧版报告把 `neffects(4)` / `(5)` / `(6)` 混着比，跨节数字不可比——这是必须先修掉的问题。

### 3.1 F1 基线：先看 `neffects()` 到底动了什么

**本节命令**

```stata
* ── 基线命令 ──
xtswitchdid (y x1) (dose), group(id) neffects(6)

* ── 事后命令（四个互相独立，不改变已估的系数）──
* 每单位处理的平均总效应 → 本节的 −1.0453
estat total
estat ptrends  // 事前安慰剂检验：ℓ<0 的系数应接近 0
* 事件研究图（存图用 graph export；不要加 nograph）
estat eventplot

* ── 只改窗口，其余不动：这就是下面那张阶梯表 ──
xtswitchdid (y x1) (dose), group(id) neffects(4)
xtswitchdid (y x1) (dose), group(id) neffects(8)
xtswitchdid (y x1) (dose), group(id) neffects(10)
xtswitchdid (y x1) (dose), group(id) neffects(12)
```

参数读法：

| 片段 | 含义 |
|---|---|
| `(y x1)` | 第一个括号 = **结局 + 协变量** |
| `(dose)` | 第二个括号 = **处理变量**，这里可取 0/1/2 |
| `group(id)` | 面板单位；默认聚类在**这一层** |
| `neffects(6)` | 事件研究窗口 = 首次切换后 6 期。**它直接决定 total 是多少** |

**什么时候需要它**：永远。这是所有其他开关的比较基准。

**为什么默认不够用**：`xtswitchdid` 必须知道「事件研究窗口开多长」。`neffects(6)` 意味着只看首次切换后 6 期。这不是一个技术细节——**它直接决定了你汇报的那个数字是多少。**

**不用会怎样**（即：随意选一个 `neffects` 就发）：

| `neffects` | 4 | 6 | 8 | 10 | 12 |
|---|---|---|---|---|---|
| `estat total` | −0.9507 | −1.0453 | −1.0677 | −1.0832 | −1.1351 |
| SE | .0964 | .0912 | .0860 | .0850 | .0856 |
| 可用县数 | 280 | 280 | 280 | 280 | 280 |

**单调放大，跨度约 19%。** 窗口越长，纳入的累积效应越多（真值在 ℓ=4 才封顶），所以系数绝对值越大。

**这就是「这个数字没有唯一答案」的意思。** 汇报时必须写明窗口长度，否则数字不可比。

**完整的基准输出**（`neffects(6)`）：

```
Initial      |
treatment    |      Groups          Obs   Switch out    Switch in    Absorbing
           0 |         105        1,575                       1 2          Yes
           1 |          70        1,050                         2          Yes
           2 |         105        1,575          0 1                        No
```

归一化暴露期效应：

| ℓ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 效应 | −0.6334 | −0.4573 | −0.3524 | −0.3611 | −0.2624 | −0.2256 |
| SE | .1165 | .0595 | .0402 | .0450 | .0255 | .0216 |

`estat total` = **−1.0453**（SE `.0912`）。

**平行趋势**（`estat ptrends`）：

| placebo | −4 | −3 | −2 | −1 |
|---|---|---|---|---|
| 效应 | (omitted) | — | — | −0.0429 |

`chi2(5) = 4.44`，`Prob > chi2 = 0.4879`。**不拒绝平行趋势，基准可信。**

ℓ = −4 被 omitted 是因为落在 **2020 年缺失处**。同时日志里有一条：

```
Warning: variance-covariance matrix is rank-deficient and 1 constraint was dropped;
results may be unstable.
```

**这条警告不是 bug。** 官方说明：当 placebo 估计的个数多于聚类数时，方差-协方差矩阵降秩，约束被自动丢弃并打印这条 note。**280 个聚类远超 6 个约束，所以这条警告在这个设定下是无害的——但你要能在答辩时说清它是什么。**

**代价**：无。`neffects` 不改变样本。

**怎么汇报**：
- 主文：写清 `neffects(6)` 并做一次阶梯表（上表），说明窗口敏感性。
- 附录：完整输出、`estat ptrends`、`estat eventplot`（`demo/output/10_f1_eventplot.png`）。

> **命令坑**：`estat eventplot` **不要写 `nograph`**，会报 `not allowed`。这个选项在 `xthdidregress` 系里存在，`xtswitchdid` 里没有。

### 3.2 F2 初始处理非零：处理不必从 0 起步

**本节命令**

```stata
* 全样本（上面 §3.1 的基线，拿来做对照）
xtswitchdid (y x1) (dose), group(id) neffects(6)

* 只留初始处理非零的县：d0 = 该县 2010 年的 dose
preserve
* 175 个县（typ1/2/4/6/7）
keep if d0 > 0
xtswitchdid (y x1) (dose), group(id) neffects(6)
restore

* 先看一眼初始水平分布，才知道自己在切什么
tabulate d0 if year == 2010
```

参数读法：

| 片段 | 含义 |
|---|---|
| `d0 > 0` | 初始剂量不为 0（即 2010 年已经处于处理状态） |
| `preserve` / `restore` | 子样本用完就还原，不影响后面节的数据 |
| `tabulate d0 if year == 2010` | 每个县只数一次（因为一个县在 2010 年只有一行） |

**什么时候需要它**：你的数据里，有些单位的处理在**第一期就已经不是 0**。

这份数据里，`d0 > 0` 的县有 **175 个**（typ1/2/4/6/7）。打开数据第一眼看到 `dose == 1` 或 `2` 出现在 2010 年，你就需要这一节。

**为什么默认不够用**：几乎所有入门 DID 教材都默认「大家一起从未处理开始」。但实际政策数据里，这常常不成立——比如你研究的是「安全规程数量」，有的厂一开始就有 1 条，有的有 2 条。

`xtswitchdid` 的识别核心正是为这种情况设计的：**它只在共享同一初始处理水平的组之间做差。**

> our estimator computes differences only between groups that share an initial treatment value

**不用会怎样**——你只能丢掉初始非零的县，样本掉 37.5%。

子样本（`keep if d0 > 0`，175 县）实测：

```
Initial      |
treatment    |      Groups          Obs   Switch out    Switch in    Absorbing
           1 |          70        1,050                         2          Yes
           2 |         105        1,575          0 1                        No
```

`estat total` = **−0.9301**（SE `.1359`），对全样本 `−1.0453` 差 **0.115**。

暴露期效应：−0.3784 / −0.4587 / −0.3167 / −0.3030 / −0.2095 / −0.2186。

**注意第 1 期反而最小**（−0.378，SE 最大 `.1741`）。原因：初始水平 1 的升档县只有 35 个（typ4），样本小。

**代价**：估计样本从 4,200 降到 2,625（175 县 × 15 年）。SE 从 `.0912` 涨到 `.1359`，**扩大约 49%**。

**决策**：如果初始非零的县在你的问题里重要（本例中它们占 62.5%），留；如果只占几个百分点且结论对它们不敏感，可以降级到附录。

**怎么汇报**：主文放一个「全样本 / 初始非零子样本」并列表；说明前者靠初始水平内部比较识别，后者损失了多少样本。

### 3.3 F3 / F4 `switchgroup()`：只留升档，或只留降档

**本节命令**

```stata
* 默认：升档县和降档县混在一起（switchgroup(all)）
xtswitchdid (y x1) (dose), group(id) neffects(6)

* 只留升档县（typ3/4/5，dose 往上走）
xtswitchdid (y x1) (dose), group(id) neffects(6) ///
        switchgroup(in)

* 只留降档县（typ6/7，dose 往下走）
xtswitchdid (y x1) (dose), group(id) neffects(6) ///
        switchgroup(out)

* 每次跑完都看一眼表头：它会告诉你哪些初始水平被整组丢掉了
* 并且留意 note：... initial treatment values dropped
```

参数读法：

| 选项 | 留下的县 | 识别发生在哪个初始水平内部 | 本节算出的 total |
|---|---|---|---|
| `switchgroup(all)`（默认） | 全部 175 个 | 0 内部 + 2 内部 | −1.0453 |
| `switchgroup(in)` | 升档的 typ3/4/5 | 0 与 1 内部 | −1.1530 |
| `switchgroup(out)` | 降档的 typ6/7 | 只剩 2 内部 | −0.8298 |

**什么时候需要它**：你的数据里**升档和降档同时存在**，而你想知道「是不是靠其中一边撑起来的」。

**为什么默认不够用**：默认 `switchgroup(all)` 把升档县和降档县**混在一个估计量里**。这份数据里，升档的真值效应是**负的**（−0.90 到 −2.06），降档的是**正的**（+0.42 到 +1.25）。混起来得到 −1.045，你完全不知道这个数字是「大家一致」还是「两边打架的净值」。

`switchgroup(in)` 只留升档县，`switchgroup(out)` 只留降档县。**这是本数据里第一个产生大差别的开关。**

**不用会怎样**（两侧同为 `neffects(6)`）：

| 设定 | total | SE | 可用县数 | 相对默认 |
|---|---|---|---|---|
| `switchgroup(all)`（默认） | **−1.0453** | .0912 | 280 | — |
| `switchgroup(in)` | **−1.1530** | .1081 | 175 | **−10.3%** |
| `switchgroup(out)` | **−0.8298** | .1675 | 105 | **+20.6%**（绝对值降 20.6%） |

两端差 **0.323**。把两者混起来的默认值 `−1.045` 落在中间——**它不代表任何一个真实群体。**

**命令 note（必须写进报告）**：

- `switchgroup(in)`：`note: 1 initial treatment value dropped because of no switchers.` 初始水平 2 只有降档县，被整组丢弃。表头剩 0（105 县）和 1（70 县）两行，共 **175 个县**，N = 2,625。
- `switchgroup(out)`：`note: 2 initial treatment values dropped because of no switchers.` 只剩初始水平 2 一行，**105 个县**，N = 1,575。

**这两条 note 是设计内的，不是错误。** 但它告诉你一件重要的事：**`switchgroup()` 不是一个「看子集」的选项，它会改变识别的对照组结构。** `switchgroup(out)` 里所有比较都发生在初始水平 2 内部——这是最干净的设定，也正是它 SE 最大（`.1675`）的原因。

**`switchgroup(out)` 的完整暴露期曲线**（这是全篇最「干净」的一组）：

| ℓ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 效应 | −0.3550 | −0.3362 | −0.2646 | −0.3322 | −0.1854 | −0.2262 |
| SE | .2225 | .0999 | .0717 | .0808 | .0510 | .0406 |

第 1 期 p = 0.111，**不显著**。这是样本从 105 县出来的诚实代价。

**代价**：
- `switchgroup(in)`：280 → 175 县，N 4,200 → 2,625。SE `.0912` → `.1081`（+19%）。
- `switchgroup(out)`：280 → 105 县，N 4,200 → 1,575。SE `.0912` → `.1675`（**+84%**）。

**方向不对称是结论，不是方法：** 如果你只报默认值，你会错过「降档虽然把约束降下去了，但结局改善幅度远小于升档造成的损害」这个发现。**这个不对称本身就是研究对象。**

**怎么汇报**：主文必须给三行并列（all / in / out），并说明 note 造成的对照组变化。这是最容易被审稿人问的一节。

### 3.4 F5 `controlgroup(never)`：只用从不切换的县做对照

**本节命令**

```stata
* 默认：never switcher + not-yet-switcher 两类对照都用
xtswitchdid (y x1) (dose), group(id) neffects(6)

* 对照池收紧：只用「到最后一期都没动过」的县
xtswitchdid (y x1) (dose), group(id) neffects(6) ///
        controlgroup(never)
```

参数读法：

| 选项 | 对照池包含谁 | 什么时候它会不干净 |
|---|---|---|
| `controlgroup(all)`（默认） | never + not-yet 两类 | 有**预期效应**时，not-yet 组已经被影响 |
| `controlgroup(never)` | 只含 never 一类 | 对照少的时候 SE 会变大 |

**什么时候需要它**：你怀疑「尚未切换」的县本身已经在受处理影响，不能当干净对照。

**为什么默认不够用**：默认 `controlgroup(all)` 用两类对照：
1. **never switchers**——到最后一期都没动过初始处理水平；
2. **not-yet-switchers**——到某个具体期为止还没动。

官方定义：

> Control groups are either never switchers... or not-yet-switchers, meaning that they keep their initial treatment value up to a specific period

第 2 类在短暴露期上样本更大（还没切的人更多），但**如果存在预期效应（anticipation），他们不干净**——知道自己明年要切，今年可能就变了。`controlgroup(never)` 把对照池限制成第 1 类。

**不用会怎样**（同为 `neffects(6)`）：

| 设定 | total | SE |
|---|---|---|
| `controlgroup(all)`（默认） | −1.0453 | .0912 |
| `controlgroup(never)` | −1.0785 | .0912 |

**差 0.033。几乎不动。**

**这个结果是本数据的一个诚实结论：在这份设计里，对照池的选择不重要。** 因为数据里没有预期效应（真值 `tau` 只在 `year >= f` 之后非零），所以 not-yet-switchers 是干净的，把过滤收紧到 never 只是换了一批对照，估计量几乎不变。

**这恰恰是它值得讲的原因：它给学生一个「开关可能没用」的样本。** 十个开关里，有的差 0.27，有的差 0.03。**在真实研究里，你必须自己试，不能照抄别人报告里的选项。**

**代价**：SE 完全相同（`.0912`）。因为 never 县有 105 个、shared 对照组仍覆盖各初始水平，样本充分。若你的数据里 never 单位很少（比如几乎所有单位最终都会被处理），这个开关会大幅损失样本——**这时候 SE 会明显变大，你要提前算好功效**。

**另一个用途**：把它当成一次**安慰剂检验**。如果 `all` 和 `never` 差得很多，说明数据里有预期效应，你的平行趋势假设更可疑。

**怎么汇报**：主文一句话带过（「对照池收紧到 never 后结论不变，差 0.03」），完整表格进附录。**「不变」也是值得报告的发现。**

### 3.5 F6 `path()`：只估一条具体路径

**本节命令**

```stata
* 第 1 步：看有哪些路径。
* pathlen(6) = 显示「初始值 + 6 期」共 7 个位置
estat paths, pathlen(6)

* 第 2 步：把路径写成变量，生成 featpath1 … featpath5
estat paths, pathlen(6) generate(featpath)

* 第 3 步：只估第 1 条路径（即 typ3 的 0→1）
xtswitchdid (y x1) (dose), group(id) neffects(6) ///
        path(featpath1)

* 想看得更短就改 pathlen；截得越短，被合并的路径越多
estat paths, pathlen(4)
```

参数读法：

| 片段 | 含义 |
|---|---|
| `pathlen(6)` | 只看前 7 个位置；第二个切换落在窗口外就看不见 |
| `generate(featpath)` | 生成 `featpath1`…，每个观测被标上它属于哪条路径 |
| `path(featpath1)` | 只拿被标为第 1 条路径的县做估计 |

**什么时候需要它**：不同单位的**路径形状不同**，而你想知道某个形状单独的效应。

**为什么默认不够用**：默认按**初始处理水平**聚合，而不是按路径。官方明确说：路径不同的组会被合并（例如 `0 1 0` 和 `0 1 1` 归到一起），关注的是每组的**首次切换**。

这意味着**默认设置下，你拿不到「哪条路径在起作用」这个信息。**

先看路径分布（`estat paths, pathlen(6)`）：

| 路径 | 县数 | 百分比 | 对应 typ |
|---|---|---|---|
| `0 1 1 1 1 1 1` | 35 | 20% | typ3（`0→1` @2012） |
| `0 2 2 2 . 2 2` | 35 | 20% | typ5（`0→2` @2017） |
| `1 2 2 2 2 2 2` | 35 | 20% | typ4（`1→2` @2012） |
| `2 1 1 1 . 1 1` | 35 | 20% | typ7（`2→1→0`） |
| `2 1 1 1 1 1 1` | 35 | 20% | typ6（`2→1` @2017） |

175 个 switcher 分属 5 条路径，**没有一条占多数。** 所以「平均效应」在这里是个高度概括的数字。

**`pathlen()` 截断的陷阱（这一段必须讲）**：`pathlen(6)` 只显示 7 个位置（1 个初始 + 6 期）。typ7 的第二次切换在 2018 年，**落在窗口外**，所以它的路径被显示成 `2 1 1 1 . 1 1`——和 typ6 的 `2 1 1 1 1 1 1` **只差一个缺失标记 `.`**。

用 `pathlen(4)` 看得更清楚：

| 路径 | 县数 |
|---|---|
| `0 1 1 1 1` | 35 |
| `0 2 2 2 .` | 35 |
| `1 2 2 2 2` | 35 |
| `2 1 1 1 .` | 35 |
| `2 1 1 1 1` | 35 |

最后两行 —— `2 1 1 1 .`（typ7，**非吸收**，2018 还会再切一次）和 `2 1 1 1 1`（typ6，**吸收**）—— **只靠 2020 年那个缺失点才区分开。** 如果 2020 年不缺失，这两条路径会被 `pathlen(4)` **合并成同一条**，两条真值完全不同的路径（typ7 的 ℓ≥7 跳到 +2.50）就被当成一回事了。

**这就是 `pathlen()` 的实质：它不是「显示选项」，它决定哪些单位被当成同类。**

`estat paths, pathlen(6) generate(featpath)` 会生成 `featpath1`…`featpath5`，可以用 `path(featpath1)` 单估：

| 设定 | total | SE | 县数 |
|---|---|---|---|
| 默认（按初始水平聚合） | −1.0453 | .0912 | 280 |
| `path(featpath1)`（只 `0 1 1 1 1 1 1`） | **−1.6167** | .2245 | 70 |

**差 0.571，SE 翻 2.5 倍。**

第 1 条路径对应 typ3 的 `0→1`，真值 ℓ=1..4 是 −0.90/−1.10/−1.30/−1.50。`−1.6167` 比真值更负——因为这条路径的估计只用了 35 个处理县 + 35 个 never 县（初始水平 0），小样本下 `theta` 的省趋势差异无法充分抵消（`se = .2245`，`−1.6167` 与真值 −1.50 的差在 1 个 SE 以内）。

**代价**：280 → 70 县，N 4,200 → 1,050。**样本掉到 1/4。**

**怎么汇报**：
- 主文：路径分布表 + 一句「路径间差异真实存在，不能只报平均效应」。
- 附录：单路径估计 + 明确写出 `pathlen()` 的选择，以及**这个选择下哪些路径会被合并**。

**如果你只做一件事**：报告里必须写下 `pathlen()` 的值，并说明在该值下有多少条不同路径被合并了。**这是审稿人最容易挑的地方。**

### 3.6 F7 `supergroup(province)`：只在同一省内部比较

**本节命令**

```stata
* 默认：跳省比较。同一 typ 的县散在 28 个省里
xtswitchdid (y x1) (dose), group(id) neffects(6)

* 只在同省内比较：province 就是那个「超组」变量
xtswitchdid (y x1) (dose), group(id) neffects(6) ///
        supergroup(province)

* 先看一眼嵌套结构到底存不存在（每省多少县）
tabulate province
```

参数读法：

| 片段 | 含义 |
|---|---|
| `supergroup(province)` | 比较只在同一 `province` 内部进行 |
| `province` 的取值数 | 28 个超组；每省 10 个县 |
| 不写 `supergroup()` | 所有县可互相做对照，跨省漂移直接进估计 |

**什么时候需要它**：你的单位**嵌套**在更高层结构里，而更高层有自己的趋势。

这份数据里，县嵌套在省里（每省 10 个县），而且我们**故意**让省有各自的趋势：

```stata
* 只截两者差异最关键的两行：省趋势的抽取和它在结局里的用法
* 每省抽一个数，全省共享
by province: gen double theta = rnormal(0, 0.04)
* （实际脚本里先标 _firstp、
* 抽完之后再 by province: replace theta = theta[1]）
* theta 乘上时间 → 省特有线性趋势
gen double y = ... + (0.12 + theta)*(year-2010) + ...
```

读法：

| 片段 | 它在说什么 |
|---|---|
| `by province:` | 在省内分组执行；这里的「组」是省（10 个县 = 10×16 = 160 个观测） |
| `rnormal(0, 0.04)` | 均值 0、标准差 0.04 的正态抽样 |
| `(0.12 + theta)` | 全国趋势 0.12 加上省偏离；所以每省的斜率是 0.12 ± 0.04 量级 |
| `*(year-2010)` | 乘时间——这就是「线性趋势」的写法（不是「年份虚拟变量」） |

**为什么这个写法能制造出「违反平行趋势」的风险：** 如果 `theta = 0`，所有省趋势完全一样，平行趋势天然成立。`theta` 一非零，处理组和对照组的**省构成**不同（因为 `typ` 与 `province` 不独立），两组的平均省斜率就不一样，产生伪漂移。**默认跨省比较直接吃这个亏，`supergroup(province)` 则把比较限制在省内，趋势自动对消。**

`theta` 是省特有趋势的偏离量，只在省内共享。

**为什么默认不够用**：默认跨省比较。但 `typ = mod(id, 8)` 和 `province = ceil(id/10)` **不独立**——同一 typ 的县分散在不同省，所以按 typ 分组比较时，两组的 `theta` 均值不相等，产生一个线性漂移的伪趋势。**这个偏离会直接进估计量。**

**不用会怎样**（同为 `neffects(6)`）：

| 设定 | total | SE |
|---|---|---|
| 默认（跨省比较） | −1.0453 | .0912 |
| `supergroup(province)` | −1.0807 | **.1257** |

total 只挪 **0.035**，但 **SE 从 .0912 涨到 .1257，扩大 38%。**

**这是本数据里最反直觉的一个结果，也正是它最值得讲的地方：** `supergroup()` 的收益**不是**让点估计更准，而是**让标准误更诚实**。

为什么？因为跨省比较时，`theta` 的省间差异被当成了噪音的一部分，而聚类（`group(id)`）在县这一层，**捕捉不到省内的相关结构**。看起来 SE 小，其实是低估了。加上 `supergroup(province)` 之后，所有比较都在省内做，`theta` 被吸收掉，剩下的不确定性才是真实的。

（顺带：`theta` 的标准差是 `0.04`，属于温和设定。**如果我把 `theta` 调大，点估计的偏移会更明显——`supergroup()` 会从「诚实化 SE」变成「纠正偏差」。这是这道题可以留给学生的思考题：`theta` 调到多大，这个开关会从建议变成必须？**）

**代价**：SE 上升 38%。**这是要如实汇报的，不能藏。**

**怎么汇报**：主文并列两行（默认 / `supergroup`），**并且必须报告 SE 的上升**。只说「系数几乎不变」是误导——真正的变化在 SE 上。

**一个实用检查**：先跑默认，再跑 `supergroup()`。如果 SE 涨了很多，说明你的数据里有高层的相关结构没被聚类层捕捉到。这时候你要问自己：聚类层选对了吗？

### 3.7 F8 `raw`：这一节是全篇的核心

**本节命令**

```stata
* 默认：归一化。每单位处理、每期平均
xtswitchdid (y x1) (dose), group(id) neffects(6)

* raw：不归一化，直接报累计效应 —— 看曲线形状必须用它
xtswitchdid (y x1) (dose), group(id) neffects(6) raw

* 总效应：两种口径下完全相同，
* 所以只要跑一次 estat total 就够
estat total

* 验算分母：子样本 A（dev 恒为 1）
preserve
* typ0 never + typ3 0→1
keep if inlist(typ, 0, 3)
xtswitchdid (y x1) (dose), group(id) neffects(6) raw
xtswitchdid (y x1) (dose), group(id) neffects(6)
estat total
restore

* 验算分母：子样本 B（dev 恒为 2）
preserve
* typ0 never + typ5 0→2
keep if inlist(typ, 0, 5)
xtswitchdid (y x1) (dose), group(id) neffects(4) raw
restore
```

参数读法：

| 片段 | 含义 |
|---|---|
| 不写 `raw` | 输 **normalized**：累计效应 ÷ 累计剂量变化 |
| `raw` | 输**未归一化**：就是累计效应本身 |
| `keep if inlist(typ, 0, 3)` | 把数据压成「一条 never + 一条切换」的干净子样本，`dev` 是常数 |
| `estat total` | 不受 `raw` 影响；两种口径下输出一样 |

**什么时候需要它**：**你在读事件研究图的时候，永远。**

**为什么默认不够用**：`xtswitchdid` 默认报告的是**归一化**事件研究效应（normalized）。而「归一化」这个词不解释了分母是什么，学生极容易把它当成「当期效应」，然后得出完全错误的结论。

**这份数据把归一化的分母精确测出来了。**

看默认输出：暴露期效应从 ℓ=1 的 −0.6334 一路降到 ℓ=6 的 −0.2256，**看起来是「效应在衰减」**。

但真值 `tau` 在 ℓ=1..4 是**上升**的：−0.90 → −1.10 → −1.30 → −1.50。**数据设定的效应在变大，归一化曲线却在变小。**

**用 `raw` 看**（全样本 `neffects(6)`）：

| ℓ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| **raw** | −0.7601 | −1.0974 | −1.2687 | **−1.4443** | −1.4171 | −1.4890 |
| SE | .1398 | .1428 | .1446 | .1801 | .1377 | .1426 |
| **normalized** | −0.6334 | −0.4573 | −0.3524 | −0.3611 | −0.2624 | −0.2256 |

**raw 先升后平（−0.76 → −1.44 → −1.49），正是设计出来的动态。归一化一路降。**

### 分母到底是什么：两个单路径子样本的验算

**子样本 A**：`keep if inlist(typ, 0, 3)`（typ0 从不切换 + typ3 `0→1` @2012）。这组里 `dev = dose - d0` 恒等于 **1**。

| ℓ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| raw | −1.1178 | −1.2162 | −1.8338 | −1.9544 | −2.0582 | −1.7528 |
| normalized | −1.1178 | −0.6081 | −0.6113 | −0.4886 | −0.4116 | −0.2921 |
| **raw ÷ normalized** | **1** | **2** | **3** | **4** | **5** | **6** |

**比值恰好是 1, 2, 3, 4, 5, 6。** 误差在 4 位有效数字内为零。

**子样本 B**：`keep if inlist(typ, 0, 5)`（typ5 `0→2` @2017）。这组里 `dev` 恒等于 **2**。

| ℓ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| raw | −1.4731 | −1.5837 | −1.7571 | (omitted) |
| normalized | −0.7366 | −0.3959 | −0.2928 | (omitted) |
| **raw ÷ normalized** | **2** | **4** | **6** | — |

**比值恰好是 2, 4, 6 = dev × ℓ。**

### 归一化定律

两个子样本合起来，结论是**精确**的：

$$\text{normalized}_\ell \;=\; \frac{\text{raw}_\ell}{dev \times \ell}$$

**归一化效应 = 累计效应 ÷ 累计剂量变化。** 分母 `dev × ℓ` 随暴露期**线性增长**。所以：

> **即使真实效应在上升，归一化曲线也必然以 ≈ 1/ℓ 的速度下降。这是一个纯分母现象，不是效应衰减。**

**这就是为什么读事件研究要看 `raw`。** 归一化给出的是「每单位处理、每期平均」的口径，它在跨不同 `dev` 的组之间可比——但**它不可用来读时间形状**。

### `estat total` 的公式

顺带把 total 也验了。子样本 A：`estat total = -1.655542`（SE `.2491`）。六个 raw 的算术平均：

$$(-1.1178 - 1.2162 - 1.8338 - 1.9544 - 2.0582 - 1.7528) / 6 = -1.655542$$

**精确吻合。**

官方公式：$\hat\tau = \sum_t\sum_{\ell<t}\hat\tau_{t,\ell} \big/ \sum_t\sum_{\ell<t}(D_{t+\ell} - D_{t,1})$，即按累计剂量变化归一化。

**关键事实**：`estat total` **在 `raw` 与默认下完全相同**——两边都是 **−1.0453**（已实测确认）。**因为 total 本身就是按剂量归一化的，`raw` 只改逐期效应的显示口径，不改 total。**

所以：
- **看形状** → 用 `raw`。
- **看总效应** → 看 `estat total`，`raw` 开关不影响它。

**还有一个和缺失年份有关的现象**（子样本 B）：ℓ=4 报 `note: effect of exposure 4 cannot be estimated because of missing data.` 因为 typ5 在 2017 年切换，ℓ=4 恰好落在**2020 年**——那一年 `y` 被我们故意删掉了。**这是设计出来的，用来说明「缺失年份会吃掉暴露期」。**

**代价**：`raw` 不改变任何样本量或 SE。**它是零成本的，所以没有任何理由不看它。**

**怎么汇报**：
- **主文必须同时给 raw 和 normalized 两列**，并解释分母。
- 附上两个子样本的比值验算——这是证明「归一化在做什么」的最强证据，也是学生自己可以复现的。
- 如果只能放一张图：**放 raw 的**。

### 3.8 F9 `commonswitchers`：固定同一批 switcher

**先用一个例子说清它在解决什么。**

一个 10 家店的连锁品牌，你想看「单店营收随时间怎么变」：

- 第 1 个月，10 家店都开着 → 平均营收 = 10 家的平均
- 第 10 个月，只剩 6 家（倒了 4 家）→ 平均营收 = 6 家的平均

把这两个点连成线，营收涨了。**但这不一定是经营变好**——也可能倒掉的 4 家本来就是差店，剩下 6 家本来就强。

**问题在于：这条曲线的左端和右端，算的人不是同一批。**

映射到这份数据：

| 批次 | 开始年份 | 到 2025 年攒了几年 | 能算到第几年 |
|---|---|---|---|
| 老批（typ3/4/7） | 2012 | 14 年 | 第 1 ~ 14 年 |
| 新批（typ5/6） | 2017 | 9 年 | 第 1 ~ 9 年 |

于是 ℓ=1 有 **175 个县**出工，ℓ=10 只剩 **105 个县**（老批）。曲线越往右，出工的人被换掉得越多——**它往下走，可能是效应真在衰减，也可能只是右边换成了另一批县。**

`commonswitchers` 的做法一句话：**先定要看几年，再只留下能撑满这几年的县，所有期都用这批人算。**

效果：`neffects(10)` 时新批（70 个县）整个退出，total 从 **−1.0832** 变成 **−1.3516**——**差 0.268 就是「换人」造成的**。

下面是这件事的技术细节与实测证据。

**本节命令**

```stata
* 默认：每个暴露期各用「当时还能用」的全部 switcher
xtswitchdid (y x1) (dose), group(id) neffects(10)

* commonswitchers：所有期只用能撑满窗口的那批 switcher
xtswitchdid (y x1) (dose), group(id) neffects(10) ///
        commonswitchers

* 同一批命令在 neffects(6) 下重跑：结果逐位相同
xtswitchdid (y x1) (dose), group(id) neffects(6) ///
        commonswitchers
```

参数读法：

| 片段 | 含义 |
|---|---|
| 不写 `commonswitchers` | 每个 ℓ 用自己的可用样本；ℓ 越大样本越小 |
| `commonswitchers` | 先锁定一批人，所有 ℓ 都用这批人 |
| `neffects(10)` | 窗口一旦超过最短批次的上限，该批次就被踢出共同集 |
| 看表头 `Switch in` | 列的取值从 `1 2` 变成 `1`，就是「有人被踢出去」的直接证据 |

**什么时候需要它**：你担心**事件研究曲线上的相邻两期，其实是用不同的人群估出来的**。

**为什么默认不够用**：默认设置下，**每个暴露期各自使用当时还能用的 switcher**。手册原文：

> If `commonswitchers` is not specified, all available switchers are used for each effect, which typically means that shorter exposures are estimated using much more data than longer exposures.

这句话在这份数据上的具体含义：能撑到 ℓ=10 的只有**早批**（2012 切换，105 个县）；**晚批**（2017 切换，70 个县）最多撑到 ℓ=9。所以 ℓ=1 用着 175 个 switcher 县，ℓ=10 只剩 105 个。**把这些点连成一条曲线，你其实在比较不同人群。**

`commonswitchers` 的做法：先定窗口（ℓ = 1 … `neffects()`），再挑出**能撑满整个窗口**的那批 switcher，只用这批人估所有期。

> Note that if `commonswitchers` and `neffects()` are specified together, the common set of switchers will be common up to the maximum number of effects specified in `neffects()`.

**它有没有影响，完全取决于 `neffects()` 设多大。**

| 设定 | 共同 switcher 集 | 表头「Switch in」 | total |
|---|---|---|---|
| 默认 `neffects(6)` | 175 个（全体） | `1 2` | −1.045275 |
| `commonswitchers neffects(6)` | 175 个（全体） | `1 2` | **−1.045275** ← 逐位相同 |
| 默认 `neffects(10)` | 逐期变化 | `1 2` | −1.083156 |
| `commonswitchers neffects(10)` | **105 个（只剩早批）** | **`1`** | **−1.351594** |

`neffects(6)` 时晚批撑得住（它的上限是 ℓ=9 ≥ 6），共同集就是全体，**`commonswitchers` 是完全的空操作**——两边 total 都是 −1.045275，暴露期系数也逐位相同。

`neffects(10)` 一超过晚批的上限 ℓ=9，晚批就被踢出共同集。**证据直接印在表头上**：初始水平 0 那一行的「Switch in」从 `1 2` 变成 `1`——那个 `+2` 的晚批升档县（typ5）不再作为 switcher 参与。

**决定性证据：A 与 B 有两期逐位相同。**

| ℓ | 对应年份（早批 / 晚批） | 默认 `neffects(10)` | `commonswitchers` | 相同？ |
|---|---|---|---|---|
| 1 | 2012 / 2017 | −.6333772 | −.7698826 | 否 |
| 2 | 2013 / 2018 | −.4572625 | −.6515508 | 否 |
| 3 | 2014 / 2019 | −.3524207 | −.4962023 | 否 |
| **4** | 2015 / **2020 缺失** | **−.3610807** | **−.3610807** | **逐位相同** |
| 5 | 2016 / 2021 | −.2624189 | −.3111673 | 否 |
| 6 | 2017 / 2022 | −.2256004 | −.2513715 | 否 |
| 7 | 2018 / 2023 | −.2004490 | −.2468987 | 否 |
| 8 | 2019 / 2024 | −.1631770 | −.1971849 | 否 |
| 9 | **2020 缺失** / 2025 | −.1054065 | *omitted* | — |
| **10** | 2021 / **2026 超出** | **−.1926439** | **−.1926439** | **逐位相同** |

两处相同不是巧合：ℓ=4 落在 2020 缺失年、ℓ=10 的年份超出面板，**晚批在这两期本来就无法参与**。A 在这两期用的样本正好只剩早批，于是和 B 重合。

反过来，ℓ=1/2/3/5/6/7/8 —— 晚批能参与的每一期 —— A 与 B 全都不同。**差别 100% 来自「晚批在不在里面」。**

ℓ=9 是反过来的例子：对**早批**来说 ℓ=9 落在 2020 缺失年，所以 B（只剩早批）整期丢掉。而 A 的 ℓ=9 是**纯晚批**估出来的：−.1054。单独只跑晚批，ℓ=9 = **−.1053**，几乎一样。

**为什么两批的差别能大到 0.268**：因为两批的真实效应本来就差近一倍。把两批分开单独跑：

| 样本 | 用上的县 | 初始水平 1 | total | neffects |
|---|---|---|---|---|
| 早批 + never（typ0/1/2/3/4/7） | 210 | 保留 | **−1.4027** | 6 |
| 晚批 + never（typ0/1/2/5/6） | **140** | **丢掉** | **−.7471** | 10 |

（晚批样本里初始水平 1 只有 never 县、没有 switcher，Stata 整组丢掉 → `note: 1 initial treatment value dropped because of no switchers.`；可用期数上限 9 → `note: a maximum of 9 effects can be estimated in this sample.`）

短暴露期的 (t, ℓ) 对数最多，而 A 在这些期混入了效应较小的晚批，所以 **A 的 total 反而比 B 更靠近 0**。B 把晚批踢出 switcher 集，所有期都用效应更大的早批，total 就更负。

**一处容易误解的地方**：`commonswitchers` **只限制 switcher，不限制对照池**。手册明确：

> it does not restrict which groups can be used as controls and in particular does not enforce a common set of control groups.

证据：B（−1.3516）和 C（真的把 typ5/typ6 从数据里删掉，−1.4027）仍差 0.05——C 连对照池也一起删了，B 还留着晚批县当对照。

**这是十个开关里差别最大的一个（0.268），比 `switchgroup(out)` 的 0.323 略小，但远大于 `controlgroup` 的 0.033。**

**回到第一版数据的对比**：第一版 DGP 里这个开关在 `neffects(6)` 下同样是**彻底的空操作**（total 与默认**在 4 位有效数字上完全相同**）。原因就是上面那条：`neffects(6)` 没超过晚批上限，没有一个人被踢出共同集。

**这正好说明第 1 节为什么要花那么大力气重造数据**：v1 里两批的效应是同一个对称斜率，就算把 `neffects` 拉过晚批上限，差别也不会大。v2 设计了批次异质（`ramp` 0.20 vs 0.12），这个开关一被激活就给出 0.268 的差别。**一个在旧数据上「没差别」的开关，不一定是没用的开关，可能是你的数据没把它需要的东西造出来。**

**命令 note**：`note: effect of exposure 9 cannot be estimated because of missing data.` 固定 switcher 集之后，可用期数进一步变少，ℓ=9 落进 2020 缺失区，表里显示 `0 (omitted)`。

**代价**：SE 从 `.0850` 涨到 `.1174`（**+38%**）。`commonswitchers` 用样本量换可比性。

**怎么汇报**：
- 主文并列两行，并回答一个问题：**你的曲线是「同一批人」估出来的吗？**
- 如果两者差别很大（像这里 0.268），说明你的曲线混合了不同人群，**必须报告这个敏感性**，并说明你的窗口是不是把某一批人挤了出去。
- 顺带检查 `neffects()`：**它设多大决定了这个开关有没有用**。设得不超过最短批次的上限时，`commonswitchers` 是空操作，不加白不加。

**记两句就够**：
1. 默认 = 曲线左右是两拨人；`commonswitchers` = 一条曲线一拨人。
2. 「有没有用」看 `neffects()`：没超过最短那批的上限，白加。

### 3.9 F10 面板间隔不是 1 年

**什么时候需要它**：你的面板是隔年、隔两年，或者间隔不规则。

**为什么默认不够用**：`xtswitchdid` 的时间来自 `xtset`，没有 `time()` 选项。如果你用隔年数据但 `xtset` 还是 `delta(1)`，暴露期的计数就错了——**ℓ=2 实际跨越了 4 年**。

**不用会怎样**（把年份隔年采样后重设间隔）：

```stata
* 把面板隔年采样，
* 并告诉 Stata「一年一行的间隔现在是 2 年」
* 记住当前数据状态，后面能 restore 回来
preserve
* 只留偶数年：2010,2012,…,2024（2020 缺 y）
keep if mod(year, 2) == 0
* 关键：重设时间间隔为 2 年，否则 ℓ 计数会错
xtset id year, delta(2)
* neffects(4) 实际跨 8 年
xtswitchdid (y x1) (dose), group(id) neffects(4)
* 回到全样本，不影响后面的段
restore

* 如果忘了 delta(2)：Stata 会认为相邻两行相隔 1 年，
* ℓ=2 实际跳了 4 年
```

逐行读法：

| 行 | 它在做什么 | 漏了会怎样 |
|---|---|---|
| `preserve` | 把当前内存里的数据「冻结」一份 | 后面 `keep` 会永久删掉一半数据 |
| `keep if mod(year, 2) == 0` | 只保留偶数年观测 | 不隔年就不叫隔年样本 |
| `xtset id year, delta(2)` | 重新声明时间间隔 | **不写这行，暴露期计数全错** |
| `xtswitchdid ... neffects(4)` | 在隔年样本上估计 | — |
| `restore` | 恢复到 `preserve` 时的数据 | 后续节跟着用到残缺数据 |

**`delta()` 为什么是必须的：** `xtswitchdid` **没有 `time()` 选项**，它只能从 `xtset` 那里读时间结构。`xtset id year, delta(1)`（默认）告诉它「相邻观测相距 1 年」。隔年数据里相邻行实际相距 2 年，如果还用 `delta(1)`，它会算出 `neffects(4)` 只覆盖 4 年（实际是 8 年），暴露期全错位。**面板频率和 `neffects()` 必须一起调。**

| 设定 | total | SE | 观测数 |
|---|---|---|---|
| 全样本 `neffects(4)` | −0.9507 | .0964 | 4,200 |
| 隔年样本 `neffects(4)` | **−0.9509** | .0922 | 1,960 |

**total 差 0.0002——几乎完全相同。**

**为什么这么稳？** 因为暴露期计数跟着 `delta(2)` 走：隔年样本里 `neffects(4)` 覆盖的**实际年数**和全样本 `neffects(8)` 相当。而真值在 ℓ=4 就封顶了，所以窗口再宽也加不出新东西。

**表头核对**（隔年样本）：

```
Initial      |
treatment    |      Groups          Obs   Switch out    Switch in    Absorbing
           0 |         105          735                       1 2          Yes
           1 |          70          490                         2          Yes
           2 |         105          735          0 1                        No
```

观测数 735 = 105 县 × 7 期（8 个偶数年里 2020 年缺失）。**样本减半，估计不变。**

**代价**：样本 4,200 → 1,960（**−53%**）。但 SE 反而略降（`.0964` → `.0922`）——因为隔年采样减少了 2020 年缺失造成的序列断裂。

**怎么汇报**：
- 主文一句话：「隔年采样后结论不变，但样本减半」。
- 附录：完整表头与 `xtset ... delta()` 的写法。

> **这道题的教学价值**：它让学生看到「面板频率」是一个**设计选择**，不是数据给定的条件。而且频率变了，`neffects()` 的含义也变了——**这两个参数必须一起调，不能只改一个。**

## 4. 十个开关一张卡

| # | 开关 | 什么时候必须动它 | 用了之后 total | 关键代价 | 进主文？ |
|---|---|---|---|---|---|
| F1 | `neffects(#)` | 永远，先定窗口 | −0.951（4）→ −1.135（12） | 无样本代价，数字跨度 19% | ✅ 必报 |
| F2 | 初始非零子样本 | 首期就有人被处理 | −0.930 | N −37.5%，SE +49% | ✅ |
| F3 | `switchgroup(in)` | 升降档并存 | −1.153 | N −37.5%，SE +19% | ✅ 必报 |
| F4 | `switchgroup(out)` | 升降档并存 | −0.830 | N −63%，SE **+84%** | ✅ 必报 |
| F5 | `controlgroup(never)` | 怀疑有预期效应 | −1.078 | 本例 SE 不变 | ❌ 附录 |
| F6 | `path()` | 路径形状不同 | −1.617 | N −75%，SE ×2.5 | ✅ + 写清 `pathlen` |
| F7 | `supergroup()` | 单位嵌套在高层层级里 | −1.081 | **SE +38%** | ✅ 必报 SE |
| F8 | `raw` | **读事件研究时永远** | total 不变（−1.045） | **零成本** | ✅ 必报 |
| F9 | `commonswitchers` | 担心各期样本不同 | −1.352 | SE +38%，差 0.268 | ✅ |
| F10 | `delta()` | 面板不是逐年 | −0.951 | N −53%，结论不变 | ❌ 附录 |

**三条要点：**

1. **没有唯一正确的 total。** 这张表里从 −0.830 到 −1.617，跨度接近 2 倍。**任何只报一个数字的报告，都必须写明其余九个开关的设定。**
2. **差得最多的是 `commonswitchers`（0.268）和 `switchgroup(out)`（0.323），差得最少的是 `controlgroup`（0.033）和隔年采样（0.0002）。** 这个排序本身是数据的性质，不是命令的性质——换一份数据会变。**你必须自己跑。**
3. **`raw` 是唯一零成本的开关，但它改变你读曲线的方式。** 不看它，你很可能把「分母在线性增长」误读成「效用在衰减」。

## 5. 文献与外部材料

### 5.1 方法本体

- **de Chaisemartin, C. & D'Haultfœuille, X. (2026).** "Difference-in-Differences Estimators of Intertemporal Treatment Effects." *Review of Economics and Statistics*, 108(4): 863–880. NBER WP 29873.
  → `xtswitchdid` 背后的论文。提出「错时首切换」（staggered first switch）设计下的事件研究估计量，允许处理非二元、可非吸收，并允许处理有滞后。
- **Stata 官方手册**：`https://www.stata.com/manuals/causalxtswitchdid.pdf`
- **Stata 功能页**：`https://www.stata.com/statanow/DID-with-switching-treatments-for-panel-data/`

### 5.2 为什么传统方法会崩（第 2 节的理论根据）

- **Goodman-Bacon, A. (2021).** "Difference-in-differences with variation in treatment timing." *Journal of Econometrics*, 225(1): 254–277.
  → TWFE 等于所有 2×2 DID 的**方差加权平均**；当处理效应随时间变化时，已处理单位会充当对照，产生**负权重**，严重时**系数符号都反过来**。这是 TD2 队列大小关系颠倒、TD3 单系数失真的理论解释。
- **Callaway, B., Goodman-Bacon, A. & Sant'Anna, P. H. C. (2021/2024).** "Difference-in-Differences with a Continuous Treatment."
  → 连续处理的 TWFE 权重同样不直观、**可以为负**，且对处理取值分布敏感——即使不存在错时问题。
- **de Chaisemartin, D'Haultfœuille & Vazquez-Bare (2024).** *AEA Papers and Proceedings*, 114: 610–613.
  → 连续处理、无 stayers 的识别问题。

### 5.3 命令族定位（承接 REPORT-09）

| 命令 | 支持的处理 | 输出 |
|---|---|---|
| `didregress` / `xtdidregress` | 二元、吸收、错时 | 单一 ATET |
| `hdidregress` / `xthdidregress` | 二元、吸收、错时 | 异质 ATET（分队列） |
| **`xtswitchdid`** | **二元/多值、可逆、非吸收** | **事件研究效应（逐暴露期）** |
| `did_multiplegt_dyn` | 连续剂量、无 stayer | 非归一化 `DID_ℓ`（默认）+ 可选归一化 |

`did_multiplegt_dyn` 的默认输出是**非归一化**的，并可选归一化版本（当前与滞后效应的加权平均），另带 dynamic placebo。**两者的默认口径正好相反**——`xtswitchdid` 默认归一化，`did_multiplegt_dyn` 默认不归一化。**换工具时一定要看默认，不要想当然。**
